Snow Surfer 🎿❄️

A 2D snowboarding game made with Unity.

About the Game

Control the player, move through the snowy level, avoid obstacles, and reach the finish line.

Built With

• Unity
• C#
• Unity Input System

Features

• Player movement
• Snowboarding physics
• Boost system
• Crash detection
• Finish line
• 2D level
